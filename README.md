# (주)더늘봄 매장 관리 대시보드

캐시노트에서 필요한 기능만 모은 웹 대시보드입니다. 법인 전체를 합친 **통합 화면**(`/all`)과 매장별 화면(`/galbi`, `/ssam`, `/momento`, `/wedding`, `/dosi`)이 있습니다. 아이패드 사파리에서 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

| 기능 | 데이터 출처 | 상태 |
|---|---|---|
| 검색순위 | 네이버 검색 API (지역검색, 상위 5위까지) | 키 입력 시 실시간 |
| 키워드 검색량 | 네이버 검색광고 API | 키 입력 시 실시간 |
| 리뷰 | 구글 지도 Places API | 키 입력 시 실시간 (네이버·배달앱은 공식 API 없음) |
| 인스타그램 | Instagram Graph API 해시태그 검색 | 키 입력 시 실시간 |
| 매출·입금 / 계좌 / 세금 | CODEF | 샘플 (CODEF 계약 후 연결) |
| 포스 | 석갈비·쌈앤샤브·모멘토베이크: 오케이포스 / 도시곳간: 토스포스 / 웨딩하우스: 없음 | 샘플 (포스사 API 제휴 필요) |
| 웨딩하우스 행사 매출 | 직접 입력 (행사별 항목·단가·수량) → Vercel Blob 저장 | Blob 연결 시 입력 가능 |
| 매출 캘린더 | 일별 매출 달력 (웨딩하우스는 행사 매출 기준) | 매출 데이터 연동에 따름 |
| 비용 · 손익 | 직접 입력 + 이카운트 등 엑셀(.xlsx/.csv) 가져오기 → 월 손익·분류별·매장별 | Blob 연결 시 입력 가능 |
| 매일 리포트 | 위 데이터 요약 → 텔레그램 | 봇 토큰 입력 시 매일 22시 발송 |

키가 없는 항목은 **샘플** 배지와 함께 예시 데이터가 표시되고, 키를 넣으면 **실시간**으로 바뀝니다.

## 매장 설정

매장 목록·키워드·해시태그·지역은 `lib/config.ts`의 `DEFAULT_STORES`에 있습니다. 코드 수정 없이 바꾸려면 같은 형식의 JSON 배열을 `STORES_JSON` 환경변수에 넣으면 됩니다. 세금·계좌는 법인 단위라 통합 화면에서만 보입니다.

## 행사 매출 저장소 (웨딩하우스)

포스가 없는 웨딩하우스는 `/wedding/events`에서 행사를 직접 입력합니다. 입력 내용은 Vercel Blob(비공개)에 저장됩니다.

1. Vercel 프로젝트 → **Storage** → **Create Database** → **Blob** 선택
2. 접근 방식은 **Private**, 프로젝트에 연결 (`BLOB_READ_WRITE_TOKEN`이 자동 추가됨)
3. **Redeploy**

내 컴퓨터에서 `npm run dev`로 실행하면 `.data/` 폴더에 저장됩니다.

## 이카운트 ERP 연동

이카운트 오픈API는 판매·구매 **입력**이 중심이고 장부(전표) **조회**는 확인되지 않아, 비용은 엑셀로 가져옵니다.
이카운트에서 계정별원장·지출내역 등을 엑셀로 내려받아 `비용 · 손익 → 엑셀 가져오기`에 올리면 날짜·금액·적요·계정 열을 자동으로 찾고, 계정명으로 분류(식자재·인건비·임대료 등)를 추정합니다. 같은 날짜·금액·거래처는 중복으로 건너뜁니다.

## 설정

`.env.example`을 `.env.local`로 복사해서 값을 채우거나, Vercel 프로젝트의 Environment Variables에 같은 이름으로 넣습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
```

- `GET /api/report` — 전체 데이터와 요약 문장(JSON)
- `GET /api/notify` — 텔레그램 발송 (`Authorization: Bearer $CRON_SECRET` 필요, `vercel.json` cron이 매일 호출)
